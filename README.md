# Kingsley's Digital Canvas

Create a premium frontend developer portfolio website for Kingsley, a frontend developer based in Nigeria. The goal is to attract freelance clients, remote jobs, and software contracts.

Design style:
- Modern dark theme with subtle glassmorphism and neon accents
- Black background with purple and blue gradients
- Smooth animations and micro-interactions
- Fully responsive for mobile, tablet, and desktop
- Professional, futuristic, and developer-focused aesthetic
- Fast loading and SEO-friendly

Pages and sections:
1. Hero Section
- Large introduction: 'Hi, I'm Kingsley'
- Title: Frontend Developer
- Strong call-to-action buttons: View Projects and Hire Me
- Profile image area with stylish layout
- Animated background effects

2. About Section
- Professional summary
- Skills overview
- Years of experience area

3. Skills Section
- HTML, CSS, JavaScript, TypeScript
- React
- Next.js
- Tailwind CSS
- Git and GitHub
- Responsive Design
- UI/UX Implementation
- Interactive skill cards with animations

4. Projects Section
- Modern project grid
- Project cards with image, description, technology stack, live demo link, and GitHub link
- Featured project support

5. Services Section
- Frontend Development
- Landing Pages
- Dashboard Development
- Website Optimization
- API Integration

6. Experience Timeline
- Professional journey timeline

7. Testimonials Section
- Client reviews carousel

8. Contact Section
- Contact form
- Email, LinkedIn, GitHub, WhatsApp links

9. Footer
- Social links
- Copyright section

Features:
- Smooth scrolling navigation
- Sticky navbar
- Dark/light mode toggle
- Project filtering by technology
- Download CV button
- Scroll progress indicator
- Framer Motion style animations
- Professional loading animation

Content management:
- Make all portfolio content easily editable.
- Include placeholder projects and profile image placeholders.

Technical requirements:
- Build with React and modern frontend best practices.
- Use reusable components.
- Ensure accessibility and responsive design.
- Generate polished production-quality UI suitable for a senior frontend developer portfolio.
